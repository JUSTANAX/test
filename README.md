# MM2Value

Оверлей ценностей Murder Mystery 2. Показывает цену каждого предмета в левом
нижнем углу его иконки внутри игрового окна трейда и считает итог обеих сторон.

## Как устроено

```
sv_parser.py  ──▶  Wayback  ──▶  sv_values.json
                                      │
game_items.json (дамп из игры) ───────┤
                                      ▼
                             match_report.py
                                      │
                                      ▼
                            build_game_map.py
                                      │
                                      ▼
                           data/mm2_values.json
                                      │
                      ┌───────────────┴───────────────┐
                      ▼                               ▼
          raw.githubusercontent.com        Workspace/mm2_values.json
                      │                               │
                      └──────────▶ overlay.lua ◀──────┘
                                   (URL, иначе файл)
```

Сопоставление имён целиком сделано на Python. В игре оверлей берёт цену прямым
доступом по `ItemID`, который является внутренним ключом базы MM2 — никакого
разбора строк в рантайме.

## Обновление ценностей

```bash
python update.py
```

Гонит три шага и падает на первом же сбое. После этого запушить
`data/mm2_values.json`, если используется GitHub-зеркало.

Ценности на сайте двигаются пачками раз в 2–5 дней. Чаще раза в сутки запускать
бессмысленно — в архиве не будет нового снимка.

## Запуск оверлея

Выполнить `overlay/overlay.lua` в экзекьюторе, находясь в MM2. Повторный запуск
безопасен: скрипт демонтирует предыдущую копию.

Проверить без второго игрока:

```lua
_G.MM2Value.simulate(
  { { "TravelerGunChroma", 1, "Weapons" } },
  { { "VampireAxe_Silver", 1, "Weapons" } }
)
```

## Обновление игровой базы

Нужно только когда в MM2 добавили предметы. Запустить `overlay/dump_items.lua`
из Madium, затем скопировать `mm2_game_items.json` из Workspace в
`data/game_items.json`.

## Что важно знать про данные

**Прямой доступ к supremevalues.com закрыт.** Сайт стоит за Imperva/Incapsula,
WAF отдаёт HTTP 200 и заглушку на 210–850 байт. Проверять успех по коду ответа
нельзя — только по числу разобранных предметов. Данные берутся через
Wayback Machine в режиме `id_`.

**Хрома-предметы носят то же `ItemName`, что и обычные.** `SeerChroma` в базе
игры имеет `ItemName = "Seer"`, но на сайте это разные предметы с разной ценой.
Сопоставление идёт по внутреннему ключу, а не по имени.

**Имена не уникальны.** `Batwing` существует как ancient за 42 и как godly за
1 000 000. Ключ всегда пара «имя + категория».

**Числовая цена есть не у всех.** Примерно 40% каталога сайт оценивает бартером
(`x4 T1 Legendaries`). Такие предметы показываются серым «?», в сумму не
попадают, а их бартерный текст уходит в панель итогов. Итог всегда считается по
неполному набору, и панель это явно показывает.

Текущее покрытие: 1041 из 1080 игровых предметов сопоставлено (96.4%),
из них с числовой ценой 470. По годли — 97% сопоставлено, 84% с ценой.
